다중 창 입장 (최대 4개)

선택한 창들을 약 30초 주기로 순환하며 입구맵이면 입장, 사냥맵이면 그대로 둡니다. 2개 이상 선택 시 입장 유지만(사냥은 게임 내 자동사냥), 1개만 선택하면 그 창으로 기존 로직(대야 스킬/칸첸 아이템)이 돕니다. 아무것도 선택 안 하면 기존과 동일(첫 번째 창).

'창 감지'를 눌러 게임 창을 확인하세요

보통은 쓸 일이 없습니다 — 한글 11,172자가 전부 내장돼 있어서 어떤 캐릭터 이름이든 어느 PC에서든 그냥 읽힙니다. 그래도 (모름)으로 나오는 게 있으면 그 창을 고르고 화면에 보이는 그대로 입력해 저장하세요. 틀리게 읽느니 모른다고 하도록 만들어져서, 읽히기만 하면 그 값은 맞습니다.

입장 (입구맵 대야산기슭) — o → Enter → Enter → ESC (각 1~3초 랜덤 대기)

실제 입력되는 키는 아래 로그에 [대야] [스킬] 'd' 사용 형식으로 실시간 표시됩니다.

창 전환 (전역 핫키)

창을 슬롯에 기억해두고 어디서든 핫키로 그 창으로 전환합니다. 바람의나라뿐 아니라 카카오톡 등 아무 창이나 가능합니다.

Ctrl+Shift+1~5 — 현재 맨 앞 창을 슬롯에 등록
Shift+F1~F4, Alt+5 — 슬롯의 창으로 이동 (각 슬롯의 핫키는 카드에 표시)
전환 시, 슬롯에 적어둔 텍스트를 클립보드에 복사합니다 (붙여넣기는 직접 Ctrl+V).
※ 슬롯/텍스트는 앱 실행 중에만 유지됩니다(껐다 켜면 재등록). 등록은 UI 버튼으로도 가능합니다.

캐릭터 관리

프리셋
자동사냥: 순환에 참여해 게임 내 자동사냥 실행 / 동시실행: 순환에서 빠지고 다른 캐릭이 사냥하는 동안 메인화면 칸첸·대야를 병행 실행 (전환 순간에만 잠깐 멈췄다 이어서 돎). 동시실행 캐릭도 아래 "동시실행 후 자동사냥 시간"을 설정하면 다른 캐릭들이 다 끝난 뒤 맨 마지막에 자동사냥 턴을 받습니다
실행 순서: ① 다른 캐릭들이 순서대로 자동사냥 (이 캐릭은 그동안 동시실행) → ② 동시실행 시간이 다 되면 종료하고 대기 → ③ 다른 캐릭 자동사냥이 모두 끝나면 맨 마지막에 이 캐릭이 이 시간만큼 자동사냥.
0 = 동시실행만 하고 자동사냥 안 함. 예: 캐릭1 사냥 180분(이 캐릭 칸첸 95분 병행) → 캐릭3 사냥 180분 → 이 캐릭 자동사냥 85분 → 전체 완료. 자동사냥할 사냥터는 아래에 입력.
드롭다운에서 위에서부터 몇 번째 항목인지 (0 = 첫 번째)
